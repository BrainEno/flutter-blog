# 隐私政策（草案）

> **状态：草案，未发布。** 本文件描述应用当前的实际数据行为，供正式发布前
> 审阅。正式版需补充运营主体、联系邮箱与生效日期后才可在应用商店或应用内
> 公布。相关工程背景见 issue #22 / #26。

「Bottom Think」（下称「本应用」）是自托管 no-wave 后端的博客客户端。
本应用**不包含**任何广告、分析或第三方追踪 SDK。

## 1. 我们处理哪些数据

### 1.1 账号与资料（保存在服务端）

- 注册仅需**邮箱地址与密码**。密码以凭证形式发送到你自己部署的 no-wave
  后端，客户端不落盘、不缓存。
- 昵称、个人网站链接、头像图片保存在服务端；头像经服务端统一重编码为
  WebP 并**剥离位置等元数据**后存储。
- 会话令牌（access / refresh token）保存在设备平台安全存储
  （iOS Keychain / Android Keystore），不进相册、不进剪贴板、不随备份导出。

### 1.2 你创作的内容（保存在服务端）

- 你发布的文章、标签、封面图与点赞记录保存在服务端。删除文章为软删除，
  服务端保留 30 天后清扫（详见回收站页的剩余天数提示）。

### 1.3 仅保存在本设备的数据（不上传）

以下数据只存在于设备本地 SQLite / 安全存储，**从不联网同步**：

- **阅读历史**：仅记录你阅读过的文章标识与展示快照，按账号隔离；退出
  登录即清除，也可在「阅读历史」页逐条或整表删除（issue #22）。
- **草稿**：编辑中的文章草稿，按文章隔离自动保存；发布或丢弃后清理。
- **离线缓存**：最近浏览过的文章列表与正文（上限 500 条），供离线阅读。
- **主题偏好**：亮 / 暗 / 跟随系统。

### 1.4 数据导出（用户主动触发）

「导出我的数据」把你的个人资料与全部文章生成为一个 JSON 文件，**直接
交给系统分享面板**，由你选择去向（ AirDrop、存档、网盘等）。导出不经过
任何我们的服务器——文件由本应用在本地生成。

## 2. 分享

阅读页的「分享」按钮仅在你配置了 `WEB_BASE_URL` 时出现，分享内容为文章
标题与公开网页链接（`{WEB_BASE_URL}/articles/{slug}`），通过系统分享面板
完成，本应用不感知接收方。

## 3. 日志与诊断

- 应用内诊断日志（关于页长按入口）保存在内存环形缓冲区，**仅在你主动
  复制或分享时离开设备**（同为你的显式操作，经系统分享面板完成）；日志
  中的令牌与敏感字段已做脱敏（issue #49）。
- 正式版发布前应承诺：崩溃与错误数据不上传（当前无崩溃收集 SDK）。

## 4. 权限使用

- **照片/文件（仅选择时）**：挑选文章封面或头像时经系统选择器访问，
  不索取整库常驻权限。
- **网络**：仅与你自己配置的 `API_BASE_URL`（及可选的 `WEB_BASE_URL`
  对应站点）通信。

## 5. 删除与退出

- 退出登录会清除本设备上的会话、阅读历史与缓存资料；服务端数据（文章、
  资料等）需按 no-wave 的删除契约另行删除（文章可在应用内删除）。
- 卸载应用即清除本设备上的全部本地数据（草稿、阅读历史、缓存）。
