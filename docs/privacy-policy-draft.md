# 隐私政策（草案）

> **状态：草案，未发布。** 本文件描述应用当前的实际数据行为，供正式发布前
> 审阅。正式版需补充运营主体、联系邮箱与生效日期后才可在应用商店或应用内
> 公布。相关工程背景见 issue #22 / #26。

「无浪潮（No Wave）」（下称「本应用」）是自托管 no-wave 后端的博客客户端。
本应用**不包含**任何广告、分析或第三方追踪 SDK。

## 1. 我们处理哪些数据

### 1.1 账号与资料（保存在服务端）

- 注册仅需**邮箱地址与密码**。注册、登录以及主动修改密码时，所需密码会作为
  凭证发送到你配置的 no-wave 后端；表单和请求处理期间短暂保留在内存，应用
  不将密码持久缓存或写入诊断。发布构建要求可信 HTTPS。
- 昵称、个人网站链接、头像图片保存在服务端；头像经服务端统一重编码为
  WebP 并**剥离位置等元数据**后存储。
- 会话令牌（access / refresh token）通常保存在设备平台安全存储
  （iOS Keychain / Android Keystore）；迁移或安全存储不可用时可能回退到应用私有
  SQLite。令牌不包含在应用提供的导出文件中；不主动写入相册或剪贴板；系统备份、
  旧副本及清理失败的保留情况取决于平台。

### 1.2 你创作的内容（保存在服务端）

- 你发布的文章、标签、封面图与点赞记录保存在服务端。删除文章为软删除，
  服务端保留 30 天后清扫（详见回收站页的剩余天数提示）。

### 1.3 仅保存在本设备的数据（不上传）

以下数据不会作为本地库自动联网同步；主动发布会把当前编辑的文章内容发送给
后端，主动导出或分享也可能把所选数据交给系统分享目标：

- **阅读历史**：仅记录你阅读过的文章标识与展示快照，按用户 ID 区分，
  不区分不同后端的相同 ID；退出时尽力清除，也可在「阅读历史」页逐条或
  整表删除（issue #22）。
- **草稿**：文章标题、正文和标签在设备本地按 API 后端、账号和文章隔离
  自动保存；本地草稿不保存所选封面文件。发布前会先保存本地快照，确认成功后
  仅在快照未变化时尝试清理；失败或结果不明确时可能保留。旧版未记录账号的
  草稿保留在本地，但不会自动归属或展示给任何账号。离线导出限制与降级风险见
  [旧草稿说明](unclaimed-drafts.md)。
- **作者搜索**：输入的关键词发送给你配置的 no-wave 服务端，搜索结果资料和
  关键词仅在页面内存中使用，不作为搜索历史持久化。头像图片沿用现有图片缓存；
  服务端和部署基础设施的访问日志由其配置决定。
- **离线缓存**：最近浏览过的文章列表与正文（上限 500 条），供离线阅读。
- **离线资料**：昵称、头像地址和网站按后端与账号分开保存，只用于离线展示。
  旧版不含账号归属的资料缓存仍留在设备上，但不会展示或自动归属给任何账号。
- **主题偏好**：亮 / 暗 / 跟随系统。

### 1.4 数据导出（用户主动触发）

「导出我的数据」从服务器获取最多 100 篇简体中文已发布作品，将其部分文字
和个人资料在本地生成为 JSON，**直接交给系统分享面板**，由你选择去向
（AirDrop、存档、网盘等）。它不包含服务端草稿、其他语言及完整正文格式
或图片，不是完整备份；生成的文件不会由应用自动上传到我们的服务器。

## 2. 分享

阅读页的「分享」按钮仅在你配置了 `WEB_BASE_URL` 时出现，分享内容为文章
标题与公开网页链接（`{WEB_BASE_URL}/articles/{slug}`），通过系统分享面板
完成，本应用不感知接收方。

## 3. 日志与诊断

- 应用内诊断日志（关于页长按入口）保存在内存环形缓冲区，**仅在你主动
  复制或分享时离开设备**（同为你的显式操作，经系统分享面板完成）；日志
  中的令牌与敏感字段已做脱敏（issue #49）。
- 正式版发布前应承诺：崩溃与错误数据不上传（当前无崩溃收集 SDK）。

## 4. 权限使用

- **照片/文件（仅选择时）**：挑选文章封面或头像时经系统选择器访问，
  不索取整库常驻权限。
- **网络**：应用访问你配置的 `API_BASE_URL`，并可能按用户内容提供的绝对
  HTTP(S) 图片地址请求第三方主机；配置 `WEB_BASE_URL` 后，站点相对正文资源
  也可访问该站点。外部链接和分享由系统或所选应用处理。系统朗读引擎由设备
  提供，所选语音可能使用网络，详见[朗读说明](read-aloud.md)。

## 5. 删除与退出

- 退出登录会尝试清除本设备上的当前会话、对应账号的阅读历史与新版资料缓存；
  清理失败或已在途写入可能使数据保留。草稿为方便同账号再次打开而保留在设备
  上；归属未知的旧草稿及旧资料缓存也不会自动删除。
  服务端数据（文章、资料等）需按 no-wave 的删除契约另行删除。
- 卸载通常移除应用本地数据，但系统备份、平台安全存储和文件系统的保留或
  物理擦除行为取决于操作系统；不能承诺卸载后所有副本均不可恢复。
