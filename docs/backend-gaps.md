## 客户端视角

以下状态依据 no-wave 审计快照 `effeb9a7`，不代表部署或生产验收结果；完整清单见 [API 差距审计](nowave-api-gap-audit.md)：

- **我的文章与服务端草稿**：我的文章页读取账号作用域的 `GET /me/articles`（非公开作者列表），因此回收站恢复出来的草稿仍然可见，并带草稿标记；在编辑器中保存即按发布提交。结构不兼容（富文本/未知块）的草稿仍只能到 no-wave 网页编辑。旧部署没有该接口时自动回退到公开作者列表，只失去草稿可见性。
- **账号安全**（G2）：个人中心可修改登录态密码，需当前密码；输入按原样保留空格。旧版注册/登录曾自动去除首尾空格，旧账号请使用当时服务器实际收到的密码（可能不含首尾空格），不会自动尝试另一种密码。改密不自动重放；网络中断或服务器异常后密码可能已生效，但其他设备仍可能保持登录，请先使用新密码确认。服务端当前会话可能被错误撤销及异常时部分成功的问题分别见 [no-wave #129](https://github.com/BrainEno/no-wave/issues/129) 和 [#132](https://github.com/BrainEno/no-wave/issues/132)。修改邮箱（见 [账户邮箱](account-email.md)）与忘记/重置密码（见 [密码恢复](password-recovery.md)）客户端已接入；邮件默认关闭，实际投递需配置并验证，验证邮箱当前不是登录或发布的前置条件。
- **内容语言**：界面语言决定内容请求的 `locale`，首页、搜索和详情均按当前 `zh-CN` 或 `en` 请求，缓存按 backend 与语言隔离；应用仍没有繁体中文界面，`zh-TW` 仅作为作者「全部语言版本」中的已有版本可见。离线书库同样只显示当前内容语言，不把另一版本伪装成空结果或回退结果。
- **富文本和多图**：已按当前 v0/v1 契约只读展示；未知或损坏格式及升级前已压平的 no-wave 缓存会提示可能不完整。站点相对图片和链接只有显式配置可信 `WEB_BASE_URL` 才可使用。富文本编辑尚未实现，普通编辑器拒绝覆盖不兼容结构；已读取摘要会回传，但不解决并发修改，正文块 ID 会重建，空摘要仍可能由服务端重算。

部署验证和仍需服务端补齐的能力（以 [API 差距审计](nowave-api-gap-audit.md)
及对应 issue 为准）：

- **G1 删除文章**：~~待补~~ **已解决**（软删 + 回收站 + 恢复已接入，
  `purgesAt` 30 天）。
- **G2 账号安全**：客户端已接入登录态改密（需当前密码；不自动重放，结果不明时提示先用新密码确认）。服务端“保留当前会话”的语义仍有问题，见 no-wave [#129](https://github.com/BrainEno/no-wave/issues/129) 与 [#132](https://github.com/BrainEno/no-wave/issues/132)；改邮箱与密码重置客户端已接入（见上），邮件投递需单独配置和验证。
- **#23 离线发布队列**：客户端已实现持久 outbox —— 发布时离线或网络失败会把文章

  重试可能留下未被引用的封面资源（孤儿清理属于服务端范围）。细节见
  [发布队列](publish-queue.md)。
- **G3 `GET /me` 返回 email**：服务端已有返回；客户端当前仍使用本地登录邮箱。
- **媒体 `src` 字段缺 `/v1` 段**：上游小修（客户端已绕过）。
